# BOOMERANG — Guided expert workspace

Approved baseline A003 · 7 November 2026. Detailed interactions: [PRD/EXPERT-CAPTURE-DESIGN.md](PRD/EXPERT-CAPTURE-DESIGN.md).

A light workspace with a fixed-width progress rail on desktop and compact step progress on mobile. Profile → Sources → Review → Confirm → Expert questions → Ready. The main page uses generous whitespace, one primary action and readable source-backed snippets. No default fictional identity, role switch or Practise navigation item.

Palette: canvas #F7F8F5, white content, forest #173F35, charcoal #182B26, muted #63736B, accent lime #D6ED9B. Text uses system sans-serif; body 16px/1.5, main heading 36–44px with restrained tracking. Form width ~660px, larger review workspace ~900px. Primary controls have clear labels and 44px minimum hit areas. Focus, errors and states use text as well as color.

Use a segmented progress bar and visible completed-step checks, with brief width/opacity transitions and reduced-motion support. Upload processing uses actual phases, no fictitious percentages. Check and cross at snippet top-right mean Approve / Needs correction. Saving an edit requires reapproval in the Confirm pass. Sources are expandable next to content. Questions use the same revise/accept loop.

The final screen opens the manual scenario test. Answer choices hide the answer key until submission. Publication is a distinct human action after a current successful test. Empty, loading, recovery, temporary-storage and provider errors must be usable. Preserve entries across Back/Continue and failures. Example dropdown offers exactly Keller Elektro and Nordform, with explicit replacement confirmation.
